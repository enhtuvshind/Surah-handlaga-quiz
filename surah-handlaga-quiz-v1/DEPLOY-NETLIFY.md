# Netlify-д нийтлэх товч заавар

1. Энэ төслийг GitHub эсвэл GitLab руу илгээнэ.
2. Netlify дээр **Add new site → Import an existing project**-ийг сонгоод төслөө холбоно.
3. Netlify нь `netlify.toml`-ын тохиргоог автоматаар уншина. Build command: `npm run build`, publish directory: `dist/client`.
4. **Deploy site**-ийг дарна.

Сорилын бүх оноолол, автоматаар хадгалах хариулт, үр дүнгийн зураг үүсгэх үйлдэл нь хэрэглэгчийн хөтөч дээр ажилладаг. Сервер, бүртгэл, мэдээллийн сан шаардлагагүй.
