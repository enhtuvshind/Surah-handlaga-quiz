# Суралцах хандлагын сорил

Монгол хэл дээрх, Колбын үзэл санаанаас сэдэвлэсэн өөрийгөө эргэцүүлэх вэб сорил. Энэ нь албан ёсны KELP үнэлгээ биш бөгөөд суралцах хэв маягийг оношлох, баталгаатай хэмжих зорилготой биш.

## Юу багтсан бэ?

- 20 асуулт, хариулт бүрийг 1–4 хүртэл давхцахгүй эрэмбэлэх интерфэйс
- CE, RO, AC, AE гэсэн дөрвөн үйл явцын оноо
- Эхний 12 асуултаас гаргах X = AC − CE, Y = AE − RO чиглэл, түр ±6 босготой 3 × 3 профайл
- Сүүлийн 8 асуултад үндэслэсэн нөхцөл байдлын тусдаа харьцуулалт
- Автоматаар хадгалах, үр дүнгийн зураг хадгалах/хуваалцах, дахин бөглөх боломж

## Орон нутагт нээх

Node.js 22.13 ба түүнээс дээш хувилбар суусан байх шаардлагатай.

```bash
npm install
npm run dev
```

## Netlify-д нийтлэх

1. Төслийг GitHub эсвэл GitLab руу оруулна.
2. Netlify дээр **Add new site → Import an existing project**-ийг сонгож төслөө холбоно.
3. Build command: `npm run build`; Publish directory: `dist/client`.
4. **Deploy site** дээр дарна.

`netlify.toml` файл дээр эдгээр тохиргоо аль хэдийн орсон. Бүх хариулт, оноолол, үр дүнгийн зураг нь зочны төхөөрөмж дээр л хадгалагдана; сервер, бүртгэл, мэдээллийн сан шаардлагагүй.
